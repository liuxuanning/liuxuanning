# 微信读书沉淀工作流

## 目录结构

```text
Weread/
  原始摘录/
    书名 - 微信读书摘录.md
  阅读笔记/
    书名 - 研究笔记.md
```

## 两个目录的分工

- `原始摘录`：放微信读书导出的划线、想法、章节摘录。这里尽量保留原貌，只做轻微清洗，不写太多自己的发挥。
- `阅读笔记`：放真正沉淀后的笔记。这里写作者观点、论证链、你的反驳、和你工作/内容/项目的连接。

## 每本书怎么做

1. 从微信读书导出摘录，保存为 `原始摘录/书名 - 微信读书摘录.md`。
2. 阅读时或读完后，把章节理解、追问、可迁移启发补进同一个原始摘录文件。
3. 读完全书后，新建 `阅读笔记/书名 - 研究笔记.md`。
4. 把原始摘录整理成自己的判断：作者说了什么、为什么成立、哪里不确定、对我有什么用。
5. 如果这本书能转化为文章、客户材料、SOP，再从研究笔记里单独复制出来加工，不提前增加目录。

## 给 ChatGPT 的章节复盘提示词

```text
我刚读完《书名》的这一章。请帮我提炼：
1. 作者的核心观点
2. 关键论证链
3. 作者依赖了哪些证据
4. 我应该反驳或追问的地方
5. 这章对我的 GEO / 内容 / 产品 / 销售工作有什么可迁移启发
```

## 给 Codex 的全书整理提示词

```text
请基于 Weread/原始摘录/《书名》 - 微信读书摘录.md，
帮我生成 Weread/阅读笔记/《书名》 - 研究笔记.md。

要求：
- 保留作者原意，不把我的理解伪装成原文
- 区分作者观点、作者证据、我的判断、可迁移启发
- 不承诺书中无法证明的结论
- 最后给出这本书对我当前工作的 3-5 条可复用判断
```
