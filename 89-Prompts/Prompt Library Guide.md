# Prompt Library Guide

## Prompt 结构

每条 Prompt 建议包含：

- Purpose
- When to Use
- Inputs
- Prompt
- Output Format
- Quality Checklist
- Related Topics

## 命名规则

`用途 - 场景 - 版本.md`

示例：

- `Research - Source Triage - v1.md`
- `Video Script - Technical Explainer - v1.md`
- `Automation - Agent Workflow Audit - v1.md`
