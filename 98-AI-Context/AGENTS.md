# AGENTS

## Scope

These rules apply to AI agents working inside this Obsidian vault.

## Rules

- Do not save full chat transcripts.
- Save only durable decisions, workflows, lessons, preferences, and project status.
- Do not batch delete files or folders.
- Never use recursive delete commands.
- Delete only one explicit file path at a time, and only when the user clearly asks.
- Check Git root, remote, and status before staging or pushing.
- Do not print secrets, tokens, API keys, or webhook URLs.
- Keep one primary folder category per note.
- Use tags and Topic Hubs for cross-topic relationships.

## Write Targets

- Captures: `00-Inbox`
- Research notes: `04-Research`
- Content production: `05-Content`
- Project state: `06-Projects`
- Reusable prompts: `89-Prompts`
- Templates: `90-Templates`
- Durable memory: `97-AI-Memory`
- Operating context: `98-AI-Context`
