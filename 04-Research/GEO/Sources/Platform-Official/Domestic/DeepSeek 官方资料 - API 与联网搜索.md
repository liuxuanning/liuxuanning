# DeepSeek 官方资料 - API 与联网搜索

## 当前状态

已找到 DeepSeek 直接官方源：

- DeepSeek API Docs: `https://api-docs.deepseek.com/`
- DeepSeek V2.5-1210 官方发布页: `https://api-docs.deepseek.com/zh-cn/news/news1210/`

这两条资料可进入 `evidence/domestic-platform-official`。其中 API Docs 可证明 DeepSeek API 形态、模型调用和工具调用等开发者能力；V2.5-1210 发布页可证明 DeepSeek 曾公开宣布网页端上线联网搜索，并说明当时 API 暂不支持搜索功能。

## What It Says

- DeepSeek API Docs 说明 DeepSeek API 使用兼容 OpenAI / Anthropic 的 API 格式，提供模型调用、价格、限速、错误码、Agent Integrations、Tool Calls 等开发者文档入口。
- DeepSeek V2.5-1210 官方发布页说明 DeepSeek 网页端支持联网搜索，用户可在 `chat.deepseek.com` 输入框中打开“联网搜索”；该页面同时说明当时 API 暂不支持搜索功能。

## What It Can Prove

- DeepSeek 有官方 API 文档入口和开发者调用说明。
- DeepSeek 官方发布页曾公开说明网页端上线联网搜索能力。
- DeepSeek 官方发布页曾明确区分网页端联网搜索与 API 搜索支持状态。

## What It Cannot Prove

- 不能证明 DeepSeek 当前 API 已支持联网搜索。
- 不能证明 DeepSeek 会展示来源、引用角标或来源列表。
- 不能证明某品牌或网页能通过 GEO 获得 DeepSeek 引用、排名或推荐。
