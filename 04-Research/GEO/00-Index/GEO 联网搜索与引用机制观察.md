# GEO 联网搜索与引用机制观察

## 当前观察范围

本文件只整理平台官方资料中公开披露的机制线索，不做平台实测。

## 观察维度

- 联网搜索是否作为产品能力出现
- 是否展示来源链接
- 是否有引用角标或来源列表
- 是否提供搜索 API 或工具调用能力
- 是否提供智能体/插件/工作流接入
- 是否公开爬虫、robots 或内容抓取说明
- 是否解释来源选择、排序或召回逻辑

## 初步沉淀

- 海外平台官方资料更容易找到搜索、爬虫、来源展示相关说明。
- 国内平台官方资料更分散，常分布在云产品、智能体平台、帮助中心、用户协议中。
- 开发者社区投稿和服务商文章不能等同于平台官方声明。

## 明确边界

本文件不记录真实测试样本，也不使用真实测试类证据标签。
