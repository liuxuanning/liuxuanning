# AGENTS

## Scope

These rules apply to this Obsidian knowledge base.

## Safety

- Do not batch delete files or folders.
- Do not use recursive delete commands.
- Delete only one explicit file path at a time, and only after the user clearly asks.
- Do not print or commit secrets, tokens, API keys, or webhook URLs.

## Knowledge Base Rules

- New captures go to `00-Inbox`.
- Research notes go to `04-Research`.
- Content work goes to `05-Content`.
- Project state goes to `06-Projects`.
- Durable AI memory goes to `97-AI-Memory`.
- Operating context goes to `98-AI-Context`.
- One note has one primary folder category.
- Use tags and Topic Hubs for cross-topic connections.
